Overview

This project showcases an interactive Excel dashboard built to transform raw data into clear, actionable insights.
The dashboard is designed with a strong focus on clarity, usability, and decision-making, enabling users to quickly understand trends, performance metrics, and key patterns at a glance.

🎯 Objectives

Convert complex datasets into an intuitive visual format

Enable quick analysis through dynamic filters and KPIs

Present insights that support data-driven decisions

🧩 Key Features

📈 Interactive charts and visual summaries

🔄 Dynamic filters and slicers for real-time exploration

📊 Key Performance Indicators (KPIs) for instant insights

🧮 Automated calculations using Excel formulas

🧱 Clean and structured layout for readability

🛠 Tools & Technologies

Microsoft Excel

Pivot Tables

Advanced formulas
